Track VTuber livestreams in one place

VTuber Tracker is a personal desktop application for checking livestream status and upcoming scheduled broadcasts from selected VTuber channels on YouTube and Twitch.

What the app does

  • Displays selected creators and their public livestream schedules.
  • Checks for live broadcasts and upcoming YouTube streams.
  • Offers optional Windows and Discord notifications for detected live streams.
  • Stores the creator list, calendar information, and preferences in a local database on the user's computer.

How to access the application

The API client currently runs locally as a Windows desktop application. It is not a hosted website, and no public download or account registration is currently offered. This site documents the application and provides its policies for review.

For API compliance reviewers: This homepage is informational; it is not a working online demo of the API client. The developer can provide genuine application screenshots or a demonstration separately if requested.

Data sources

Public YouTube stream metadata is retrieved using YouTube API Services. Public Twitch livestream status may also be retrieved through Twitch's API. Content remains on the original platforms; the tracker links viewers to the source.
