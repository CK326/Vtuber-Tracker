Privacy Policy

This policy describes the current personal Windows desktop version of VTuber Tracker. The project uses YouTube API Services and may also use Twitch's API. This website is an informational site and does not itself provide the tracker functionality.

Information accessed

The application requests publicly available creator and livestream information, such as channel identifiers, video identifiers, stream titles, thumbnails, livestream status, and scheduled start times. It does not require viewers to sign in with a Google or YouTube account and does not request YouTube account passwords.

Information stored locally

The desktop application uses a local SQLite database (typically tracker.db) to store selected creators, stream and schedule records, display preferences, and notification state. Local configuration (typically .env) may contain API credentials and optional Discord notification settings. These files remain on the device unless the user copies, backs up, or shares them.

How information is used and shared

Public stream information is used to display a consolidated schedule and detect livestreams. The application sends requests to YouTube and, when configured, Twitch to retrieve updates. If the user configures a Discord webhook, the application sends notification messages containing stream details to the chosen Discord destination; Discord handles those messages under its own policies. Windows notifications may display stream information on the local device. The current desktop application does not operate a developer-hosted user-account service or sell user data.

Website and third parties

This informational website is hosted on GitHub Pages. GitHub may process technical access data when visitors load these pages; see GitHub's privacy statement. This site does not intentionally embed third-party advertising or analytics scripts. External links lead to services governed by their own policies.

Retention and deletion

Locally stored information remains until it is updated or deleted by the user or the application. To remove the tracker’s locally stored creator, schedule, and preference data, close the desktop application and delete its tracker.db file; doing so resets that data. To remove saved API and notification configuration, delete the local .env file. Delete any copies or backups separately. Removing the app does not remove messages already sent to Discord; manage those in Discord.

YouTube and Google policies

VTuber Tracker uses YouTube API Services. By using features that rely on YouTube, you are also subject to the YouTube Terms of Service. See the Google Privacy Policy for information about Google's data practices. The current version uses an application API key for public data and does not request Google OAuth authorization. If Google authorization is introduced later, this policy must be updated to explain it and the applicable revocation procedure.

Changes and contact

This policy will be revised if the application's functionality or data practices change. For privacy questions, contact the project maintainer through the repository's GitHub Issues page (public; do not post secrets). Developer review required: add a dedicated contact method if Google requires one, and verify every data-handling statement against the actual installed app.
